A full-stack note-taking application inspired by Google Keep, built with modern web technologies and AI-assisted development.

**What it does**

- Secure authentication with email/password and OAuth providers using Better Auth
- Drag-and-drop note organization with a responsive, Google Keep-inspired interface
- S3-compatible image uploads for note attachments
- Full CRUD operations with real-time updates

**Stack:** React, Express, PostgreSQL, Drizzle ORM, Better Auth, S3-compatible storage

**Result:** A production-ready note-taking app that demonstrates end-to-end fullstack development, from database design to responsive UI.
