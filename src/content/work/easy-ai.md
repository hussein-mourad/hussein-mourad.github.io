A comprehensive toolkit designed to simplify AI model creation, with a focus on accessibility for developers of all skill levels. Built as a graduation project at Alexandria University.

**What it does**

- Visual platform for designing AI models without writing code
- Intuitive interface for generating customized AI architectures
- Scalable, modular system design

**Stack:** React, Django

**Result:** Enabled users to design and deploy AI models through a visual interface, making AI accessible to non-technical users.
